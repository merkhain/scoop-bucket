# Merkhain scoop-bucket

Official Scoop bucket for the Merkhain early beta on Windows.

```powershell
scoop bucket add merkhain https://github.com/merkhain/scoop-bucket
scoop install merkhain/merkhain
```

See [downloads and installation](https://github.com/merkhain/releases).
Send [support requests](https://github.com/merkhain/releases/issues) to the releases repository.
